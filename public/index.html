⌨️ Shortcuts & Tips

Editor & code intelligence

  • Ctrl+SpaceCompletion popup — Java keywords, JDK types, snippet names, and identifiers from the current buffer. Arrow keys navigate, Enter inserts, Esc closes.
  • sout + TabExpands to System.out.println();. Also try soutv, serr, psvm, main, fori, foreach, while, trycatch.
  • ▶ / ▼Fold arrows in the gutter physically collapse a { … } block into one line. Click ▶ to expand.
  • Tab / Shift+TabIndent / outdent selected lines.
  • Ctrl+/ / Ctrl+D / Alt+↑Comment, duplicate, move line.

File tree & stack traces

  • Ctrl+B / 🗂️Toggle the file tree. It shows the contents of your chosen folder. Click a .java file to open it in the editor.
  • ☕Java source files. ⚙ marks .class files, 📁 folders.
  • linkStack traces like at Main.main(Main.java:8) are clickable — they open the file and jump to that line.

Run & interact

  • Ctrl+EnterRun — compile and run interactively.
  • Ctrl+Shift+EnterSave & Run — writes java/ and class/ first, then runs.
  • TerminalWhile a program runs, click the terminal and type. Input appears on the same line as the program's prompt.
  • ■ StopThe Run button turns red while executing — click to kill.

CMD mode

  • ⌨ CMDFolder-aware prompt. Commands act on your chosen folder.
  • pushSaves the editor into <folder>/java/.
  • javacjavac Main.java → <folder>/class/Main.class.
  • javajava Main arg1 arg2 — runs interactively.
💡 Tip: Everything — code, folder, tree width, args, theme, font size, mode, folds, and stdin buffer — is remembered locally.
